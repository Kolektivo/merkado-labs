# 03 - User Flows

**Purpose:** The journeys the Labs demo must support.
**Last updated:** August 14, 2026

## 1. Overview

Visitor lands on Overview, sees three doors (landlord, holder, renter), the
MRA-001 figures, and the open legal questions. Reset demo is here.

## 2. Landlord (Merkado Rent Advance)

1. **Offers** — the six-offer book.
2. **Create offer** — six steps, then save as draft.
3. **Get Now** — quote a landlord. 3-month term disabled. Above 24% cannot complete.
4. Offer detail — sale-not-loan, Passport, collections, dual-control release.

## 3. Holder (Merkado Direct)

1. Marketplace shows anonymised cards (district, grades, rent-to-market, term).
2. Offer detail shows Passport and scheduled — not promised — distributions.
3. Subscribe is closed. Sole-holder mode until M.1.2 and M.1.4 are closed.
4. Portfolio is book-entry in XCG.

## 4. Renter

1. One Pay rent page. Headline: “Your rent is unchanged.”
2. Next payment is Cg 1,800.00 to the property manager, reference MRA-001.
3. Notice is on the same page. Language buttons: English / Nederlands / Papiamentu.
4. No fee, holder, or return figures anywhere.

## 5. Privacy walls

- Payer never sees economics.
- Purchaser never sees payer identity, employer, or address.
- Purchaser never contacts the payer.
- Payer never sees the purchaser.
